## Tips for Speed

### Creating Drops Faster:
1. Keep captions short (5-10 words max)
2. Don't worry about perfect locations (reviewers don't care)
3. For music, just paste any song URL (don't spend time choosing)
4. Skip optional fields when in a hurry

### Adding Friends Faster:
1. Use real friends if possible (saves 30+ minutes)
2. If creating test accounts, use simple passwords
3. Sign out/sign in between accounts in the app's settings

### Common Issues:
- **"Profile setup error"**: Make sure username is unique and 3+ characters
- **"Location error"**: Allow location permission in iOS Settings
- **"Drop not showing on map"**: Force quit app and reopen
- **"Friend request not working"**: Check username is correct (@username format)
