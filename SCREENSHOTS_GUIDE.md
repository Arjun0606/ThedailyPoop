# 📸 Screenshot Guide for TheDailyPoop App Store

## Required Sizes

You need screenshots for at least 2 device sizes:
1. **6.7" Display (iPhone 15 Pro Max)**: 1290 x 2796 pixels
2. **6.5" Display (iPhone 14 Plus)**: 1284 x 2778 pixels

## How to Take Screenshots

### Method 1: Using Xcode Simulator (Easiest)

1. **Open Xcode** → Open `PoopDrop.xcodeproj`
2. **Select Simulator**:
   - For 6.7": Choose "iPhone 15 Pro Max"
   - For 6.5": Choose "iPhone 14 Plus"
3. **Run the app** (⌘ + R)
4. **Navigate to the screen** you want to capture
5. **Take screenshot**: 
   - **Simulator → Device → Screenshot** (from menu bar)
   - Or press **⌘ + S**
6. Screenshots save to Desktop automatically

### Method 2: Using Real iPhone

1. **Connect your iPhone** to Mac
2. **Open Xcode** → Window → Devices and Simulators
3. **Select your device**
4. **Click "Take Screenshot"** button
5. Screenshots will be the correct size automatically

## Tips for Great Screenshots

1. **Use a clean state**: No debug info, proper data
2. **Fill with content**: Have some drops, friends, stats
3. **Show key features**: Focus on what makes the app unique
4. **Good lighting**: If using real device, ensure good screen brightness
5. **No personal info**: Use test accounts

## Quick Setup for Screenshots

Run the app and:
1. **Create 3-4 poop drops** in different locations
2. **Add 2-3 test friends** (use TestFlight or multiple devices)
3. **Unlock 3-4 badges** by creating drops and hitting milestones
4. **Add reactions** to some drops
5. **Paste a Spotify/Apple Music link** in one drop

This will make your screenshots look populated and engaging!

## After Taking Screenshots

1. **Rename files** clearly:
   - `iphone_67_map.png`
   - `iphone_67_feed.png`
   - `iphone_67_composer.png`
   - etc.

2. **Verify sizes**:
   - Right-click → Get Info
   - Check dimensions match required sizes

3. **Upload to App Store Connect**:
   - Go to your app → App Store tab
   - Scroll to "App Store Screenshots"
   - Drag and drop images (up to 10 per device size)
   - Add captions below each screenshot (optional but recommended)
